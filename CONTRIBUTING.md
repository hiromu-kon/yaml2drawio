# Contributing

Thanks for your interest in yaml2drawio. Issues and pull requests are welcome.

## Setup

Node and pnpm versions are pinned in `mise.toml`, so install [mise](https://mise.jdx.dev/) first.

```sh
mise install
pnpm install
```

If your shell does not activate mise, prefix commands with `mise exec --`.

## Commands

| Command              | What it does                                              |
| -------------------- | --------------------------------------------------------- |
| `pnpm check`         | Typecheck, lint, test and format check. CI runs the same. |
| `pnpm format`        | Format files with oxfmt.                                  |
| `pnpm test`          | Run tests with Vitest.                                    |
| `pnpm dev icons <q>` | Search the icon catalog, e.g. `pnpm dev icons redis`.     |
| `pnpm catalog`       | Regenerate `catalog/aws.json` from draw.io sources.       |

## Icon catalog

`catalog/aws.json` is generated by `scripts/extract-drawio-icons.ts` from a pinned draw.io release. Do not edit it by hand.

- To add a short name such as `aws.s3`, edit `catalog/aws.aliases.json`.
- To follow a newer draw.io release, bump `DRAWIO_TAG` in the script and run `pnpm catalog`.

## Conventions

- Write code comments, test names, commit messages, issues and pull requests in English.
- `README.md` is the source of truth. When you change it, update `README.ja.md` in the same commit.
- Use [Conventional Commits](https://www.conventionalcommits.org/) (e.g. `feat: add drawio writer`) and explain why in the body.
